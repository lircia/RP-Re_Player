This folder contains test media for RP-Re_Player playback and subtitle features. All files named with the `rein` prefix are test files.

`rein.mkv` contains multiple embedded ASS subtitle tracks and can be used to test subtitle-track detection, selection, and playback. Image-based subtitles are not supported at this time.
